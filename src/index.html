AI / MCP 连接

        
让支持 MCP 的 AI 工具查询收藏与待办、批量安排日程、创建便签和整理分类。

        

            
            
        

        

        
        
在群枢等工具中添加 Streamable HTTP MCP，填写复制出的 URL 和 Authorization
            请求头。Collectify需保持运行；连接令牌在本机生成，接口只监听本机，不返回密码。AI
            写入会直接生效，可从界面查看结果。

    
工作空间数据
按需选择收藏、待办与日历、便签及偏好设置，在不同电脑之间整理和迁移。
登录资料可单独选择是否导出；文件不包含浏览器 Cookie、附件原文件和本机 MCP 连接令牌。

    


导出数据
选择这次要处理的工作空间内容。
导入前自动备份数据库。未勾选的类型不变；选择“替换”会清除该类型原有内容。导入的偏好设置按文件覆盖。
日历使用同一份待办数据；附件只保存路径。MCP 令牌和网页登录状态使用本机数据库备份保留。
