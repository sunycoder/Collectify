# 计算稿纸

`collectify.calculator` 1.0.0 是可选页面插件，要求 Collectify 5.7.9 或更新版本。Windows、macOS、Linux 共用同一套沙箱页面和 SDK；不包含原生后台、网络请求、第三方库、监听端口或后台任务。未打开时不执行计算或初始化数据。

## 使用

在“设置 → 插件 → 安装插件包”选择 `collectify.calculator-1.0.0.collectify-plugin`。首次打开创建空白稿纸，不插入示例或修改其他插件的数据。入口图标与页面图标均使用包内 `icon/calculator.svg`，从开发者指定的 `assets/计算器.svg` 原样复制。

- 每行输入公式立即计算，前面任意一行改变时，后面的引用同时重算。Enter 到下一行，最后一行按 Enter 添加一行；Shift+Enter 在同一公式中换行。
- 支持 `+ - * / % ^ **`、括号、一元正负号、科学计数法、乘号 `×` / `x` / `X` 与除号 `÷`。`%` 是取余，不是百分比后缀。`^` 和 `**` 是幂运算，右结合；`-2^2` 等于 `-4`，`(-2)^2` 等于 `4`。
- `ans` 引用紧邻上一行的结果，`_1`、`_2` 引用当前稿纸的第 1、2 行。只允许向前引用；空行、错误行、自引用和未来行明确报错，不跳过错误或保留旧结果。删行后编号重排，引用按新的行号重新计算。
- 支持 `PI` / `π`、`E`、`abs`、`sqrt`、`cbrt`、`hypot`、`pow`、`log`、`log10`、`log2`、`exp`、`sin`、`cos`、`tan`、`asin`、`acos`、`atan`、`atan2`、`ceil`、`floor`、`round`、`trunc`、`min`、`max`。三角函数参数使用弧度。`round` 半值向正无穷取整，与 JavaScript Math.round 一致，例如 `round(-1.5) = -1`。
- “公式示例”按基础、数学、三角、取整和实用场景分类。点击示例填入当前空行；已有公式时追加新行，不覆盖原内容。
- 每行可以添加备注，点击结果复制不带千分位的数值；“复制稿纸”包含标题、公式、结果和备注。
- 多张稿纸支持命名、锁定、清空和删除。锁定阻止公式、备注、标题、清空和删除，允许查看与复制；清空和删除需确认。Ctrl+L / Command+L 清空当前稿纸，仍有确认框。字号可在 16～32 之间调整，支持深色主题和窄屏。

## 精度与安全

公式通过专用语法解析器求值，不使用 `eval`、`Function` 或脚本解释器，不接受属性访问、赋值和任意函数。限制长度、词法数量、递归深度及大数范围，防止输入阻塞界面。

十进制四则运算、整数幂、取余和取整以 BigInt 有理数计算，`0.1+0.2` 得到 `0.3`，不会先转换为浮点数。常量、三角、对数、开方和非整数幂使用双精度数学函数，结果带 `≈`。最多显示 12 位小数并舍入，循环小数或过小数值也以 `≈` 提示；引用使用内部结果，不使用显示舍入后的文本。不能除以零，负数开平方、无穷或非实数结果明确报错。

## 自动保存与限制

每次输入立即通过插件 SDK 排队提交，不使用延迟定时保存。保存队列对调用时快照串行写入，避免异步旧请求覆盖新输入；状态显示“正在保存 / 已自动保存 / 保存失败”。保存失败时保留内存输入并提供重试，阻止切换、新建或删除导致未保存修改丢失。强制杀进程或在“正在保存”期间立即关闭，不能保证尚未完成的写入；正常使用以“已自动保存”为准。

数据仅存放在插件自己的 SQLite 键值空间中：`index` 保存目录与字号，`sheet:<id>` 保存每张稿纸，更新稿纸与目录在同一存储事务中提交。支持宿主全局备份、保留数据卸载后重装、明确删除插件数据。最多 60 张稿纸，每张 200 行，每行公式 1000 字、备注 200 字，单张序列化不超过 200 KB；仍受宿主总存储 8 MiB 的限制。旧版或损坏的数据读取失败时明确提示，保留原数据。
