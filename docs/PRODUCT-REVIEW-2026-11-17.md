# 产品体验检查 · 2026-11-17

范围：依据当前 Collectify 工作区实现检查，不把建议当作已完成功能；Windows 本机可验证，macOS/Linux 未在本轮实机运行。

## 本轮已完成

- 最左侧插件入口支持拖动排序、插入线、边缘自动滚动、Esc 取消；普通点击和拖动分开。
- Alt + ↑ / ↓ 可调整当前焦点入口，移动后保留焦点。排序成功或失败明确反馈。
- 顺序由宿主保存，不改插件清单，不引入业务依赖，停用/重新启用、更新及重启保留位置，新插件追加。提供恢复默认顺序。
- 排序只在初始化和保存时读写偏好，列表刷新不额外查询数据库。

## 本轮落地状态（5.7.12 / Diff 1.0.3）

- 已接入 Diff 偏好统一备份，导出前展示插件声明的覆盖范围；不导出工作正文、原文件或草稿。
- 已补通用页面离开握手和后台关闭确认，支持取消退出/停用/卸载/重载/更新/导入；Diff 支持另存文本、自愿草稿、恢复和删除。
- 已补插件详情页、权限/能力/限制/版本/平台记录与截图合同；旧目录保持兼容，缺失信息明确标注。当前预览图先覆盖 Diff，其他插件没有截图时不伪造。
- 已补通用任务贡献和精确取消，Diff 接入扫描、解析、报告与 OCR；其他插件未接入的后台活动不会冒充任务显示。
- 已把导航顺序接入宿主设置迁移并保留未知插件 ID，不自动安装/启用；补搜索空状态、Esc 清除和 Enter 打开。
- 已统一记录 Windows 实测与 Mac/Linux 未验证边界，见 PLATFORM-VERIFICATION-2026-11-17.md。未进行广场发布、跨设备同步、多标签或三方合并。

统一交互验收清单见 INTERACTION-ACCEPTANCE.md。多标签、历史记录、三方合并等增强仍需单独设计。

## 核对入口

- `src/plugin-system/registry.js`：导航顺序、插件生命周期与 snapshot 领域备份合同。
- `src/main.js`：宿主 settings 读写、插件停用及排序动作。
- `src/renderer.js`、`src/plugins.css`：导航与插件市场。
- `src/plugin-library/diff/backend.js`：偏好保存与后台工作任务；`app.js`：内存编辑、合并与会话。
- `src/plugin-library/local-search/backend.js`、`src/plugin-library/chinese-calendar/backend.js`：已有领域导入导出实现。
- `docs/DIFF.md`：格式范围和功能限制。
