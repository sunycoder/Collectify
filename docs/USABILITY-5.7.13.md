# 5.7.13 操作体验改进

本轮针对已确认的操作问题，保留各插件独立安装、更新与热插拔边界；未公开发布。

| 范围           | 改动                                                                                                                                             | 验证                                  |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------- |
| 计算稿纸 1.0.3 | 悬浮键盘整块空白均可拖动，按键保持点击；未完成公式为继续输入提示；紧凑空行与按需备注；不重复追加空行；2/4/自动小数位；删行可撤销；当前输入行高亮 | 真实鼠标拖动、计算/恢复/锁定/窄屏回归 |
| 便签、待办     | 关闭编辑框、Esc、遮罩及插件离开检查提供继续编辑/放弃/保存；附件变化也触发确认；便签筛选无结果提供清除入口                                        | smoke-usability 与完整宿主回归        |
| 本地搜索 1.2.2 | 结果/预览分隔条可拖动，双击恢复，方向键调整，宽度偏好保存；小窗口改上下排列                                                                      | 实际解析预览及分隔条回归              |
| JSON           | 错误位置可跳转；无法确定精确位置时说明并返回开头；清空可撤销，避免覆盖新输入                                                                     | smoke-usability                       |
| IP 查询 1.0.3  | 历史显示地区、运营商和时间；数据源缺失字段明确说明，兼容旧历史                                                                                   | IP 查询回归                           |
| 剪贴板 2.2.6   | Windows/macOS 的条目可直接复制并粘贴到上一应用，沿用既有平台权限与失败处理                                                                       | 宿主剪贴板回归，系统粘贴使用隔离替身  |
| 主程序         | 单入口插件自动收起二级导航，可手动展开；已安装插件页显示可更新版本并直接更新                                                                     | smoke-usability、导航与插件安装回归   |

小数位仅改变显示与单项复制，行引用继续使用原精度；自动最多显示 12 位，不声称无限精度。删行撤销在当前会话保留 10 秒；切换稿纸后先返回原稿纸再撤销。保留原稿纸和全文复制语义。

数学键盘是插件页面内的悬浮面板。位置记忆、边界限制、Esc 取消拖动及一键恢复继续有效。交互控件不触发拖动。

本轮实际执行环境是 Windows，macOS/Linux 没有本轮实机验证。各测试结果以最终命令执行回执为准，不将测试入口等同于通过。
