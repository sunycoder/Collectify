# 剪贴板历史 2.1.1

2.1.1 需要 Collectify 5.6.0 或以上版本，可通过“发现插件”或“安装插件包”更新。已有 1.0 的文本历史会迁入新版，不开启自动采集；已有 2.0 会继续使用原数据库。独立发布规则见 [官方插件目录维护](../plugins/README.md)。

## 操作

- 顶部搜索文本或文件名；分类为全部、文本、图片、文件和收藏。
- 点击“开启后台采集”后，切换插件、切换到其他应用或隐藏主窗口仍能采集；关闭主窗口会驻留托盘。完全退出 Collectify 后停止。
- 点击“暂停采集”立即停止读取。停用或卸载插件会关闭隔离后台页面。
- 开关状态保存在插件自己的数据库中；已主动开启时，下次启动 Collectify 会继续采集。未开启时不读取。
- 单击记录只选中，双击或复制按钮恢复其原类型；复制不改变历史顺序与时间。
- 右键菜单提供复制、执行粘贴、悬浮中转、收藏、展开和删除；支持方向键、Enter、Ctrl/⌘ C、Delete、Esc。
- Windows 的“执行粘贴”先复制再隐藏 Collectify，向恢复焦点的外部应用发送 Ctrl+V。只由前台插件主动调用，后台不能执行；其他平台保持手动粘贴。若外部应用以更高权限运行，系统可能拒绝发送按键。
- “悬浮中转”打开独立置顶窗口，与主窗口共用本插件数据和采集进程；停用插件时一起关闭。
- 删除和清空不会清空系统剪贴板，但会保留当前内容的处理标记，避免下一次轮询把删除的内容加回来。复制图片按像素内容判重，避免编码变化误判成新记录。
- 星标收藏保留该内容；“清空未收藏记录”和容量回收不删除收藏。
- 图片显示预览和尺寸，可展开；文件显示名称与路径，文本可展开查看全文。

## 数据与限制

历史只保存在 `plugins/collectify.clipboard-history/data.sqlite`，不会上传给服务器或 MCP 开发工具。文件记录保存文件列表及剪贴板格式，不复制、读取文件原文；原文件被移动或删除后，目标应用可能无法粘贴。

最多 100 条、约 6 MB 内容预算；文本最多 64 KB，单张图片最多 4 MB，文件列表最多 100 个路径。超出限制显示原因，不覆盖已有记录。收藏占满空间时提示用户清理，不自动删除收藏。后台每秒检测一次，极短时间内连续多次复制可能只记录检测时的内容。

图片采用分块键值保存，索引、内容和旧块删除在同一 SQLite 事务中提交。继续沿用全局插件数据备份，不另建业务文件；复制图片恢复 PNG/JPEG，复制文件恢复文件列表。离开页面不触发网络请求。

## 运行边界

插件清单通过 `background` 声明隔离 HTML 后台页面，需额外声明 `background` 和 `clipboard.background` 权限。宿主只提供隔离生命周期、存储批次、剪贴板格式与本插件消息通信；记录、分类、收藏、清理和界面均由插件代码维护，不加载第三方 Node.js 后台。

本轮在 Windows Electron 45.2.3 中，以注入的剪贴板数据验证文本、图片、文件、隐藏窗口采集、暂停、复制格式、启停和数据保留。测试未读取真实系统剪贴板；macOS/Linux 未实机验证。

类型图标从 iconfont 公开页获取并随插件打包，来源记录在 `icons/SOURCES.md`。执行粘贴测试使用接口替身；Windows 助手经过 PowerShell 解析和 C# 结构编译验证，未向真实外部应用发送按键。
