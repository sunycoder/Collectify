# 5.7.16 操作体验改进

| 场景         | 处理结果与边界                                                                                                                                                                                            |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 数学键盘显示 | 切换插件、打开宿主遮罩、隐藏或最小化主窗口时隐藏；返回恢复原窗口。手动关闭后保持关闭，停用/卸载回收。桌面待办和剪贴板中转继续独立，不套用辅助键盘规则。                                                   |
| 键盘输入目标 | 展示稿纸名称、当前行及公式，长名称可悬停查看；切换稿纸、输入或修改标题后同步。支持临时取消置顶。                                                                                                          |
| 公式撤销     | 键盘输入、点击按键、选区替换和清空本行共用有界内存历史；支持撤销/重做及 Ctrl/Command+Z、Ctrl/Command+Shift+Z。历史不写入备份或磁盘，最多 80 行、每行 40 次。删行撤销继续独立保留 10 秒。                  |
| 长内容       | 长公式换行、长结果断行；键盘公式区可滚动；便签长标题折行、正文可滚动；搜索列宽可调，完整路径保留悬停查看。                                                                                                |
| Diff 导出    | 导出前显示文件、工作表、差异条目/片段和生效规则。仅差异移除未更改文本片段及完整图片；包含上下文保留原文本或当前画面。表格两种范围都只列差异单元格，界面明确说明。导出前重新核对内容，变化后要求再次确认。 |
| 本地搜索     | 名称/目录/大小/修改时间四列，分隔条拖动或方向键调宽，双击恢复；列宽保存在插件偏好。路径截断优先显示末端，悬停保留全文。                                                                                   |
| 便签排列     | 最近修改与手动固定顺序两种模式。首次启用手动排列冻结当前顺序；支持拖动或前后移动。编辑不跳位，筛选不改变底层顺序，重启与备份恢复保留。                                                                    |

不增加剪贴板单条删除撤销。剪贴板中转、桌面待办独立窗口和收藏资料卡已有回归，确认独立/跟随边界后仅修改实际遗漏的宿主隐藏链路。

本轮在 Windows 执行 203 项自动化测试、完整宿主回归，以及计算稿纸/本地搜索/Diff 与专项操作回归；未在 Mac/Linux 本机执行本轮新增行为。跨平台构建成功或历史测试通过，不替代本轮验证。

本地版本：主程序 5.7.16、计算稿纸 1.0.7、本地搜索 1.2.3、Diff 1.0.6。主程序升级包含便签与公共窗口能力，可选插件仍分别安装。发布验证结果见本版本的 CI 与发布流水线。
