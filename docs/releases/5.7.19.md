# Collectify 5.7.19

- 搜索入口统一为“搜索工作台”，可按全部、插件或内容筛选，支持查找收藏、待办、便签和计算稿纸并直接定位。
- 插件支持选择多个批量更新，逐项报告结果并保留失败项供重试；本地开发支持扫描项目或插件集合目录、勾选批量加载、记住目录及同版本重载，保留原有数据和启停状态。
- 待办支持每天、工作日、每周、每月重复及跳过本次；完成时原子生成下一次，月底跨短月份后保留原日期规则，重新勾选不重复生成。
- 收藏支持同资源环境分组、直接切换及生产环境标记；计算稿纸支持中文或英文命名变量及后续行自动重算。
- 本地搜索可选择两个文件直接交给 Diff；未安装或停用时引导至插件管理。
- Diff 支持最多六组对比并保留各组内容与视图，保存本地路径组合与规则，路径失效可重新定位；保存组合收进可搜索列表。表格支持行内文本、列和变更类型筛选、复制当前行，并压缩顶部工具栏。
- 剪贴板支持文本放大、选区复制与自适应预览高度；将会切换外部应用的粘贴操作移入明确标注的右键菜单，修复按钮越界。
- 统一相关静态和动态弹窗的外部点击、Esc 及拖选保护；搜索设置、单元格编辑未保存时提供继续编辑、放弃及保存后关闭。

本次插件版本：收藏 1.0.4、待办 1.0.4、便签 1.0.5、计算稿纸 1.0.9、剪贴板历史 2.2.7、本地搜索 1.2.5、Diff 1.0.8。上述插件最低需要 Collectify 5.7.19，请先升级主程序。

本地 Windows 验证包括 219 项测试、相关插件实际页面交互回归、代码和契约检查。Windows、macOS、Linux 的构建及自动化回归结果以本次发布流水线为准；macOS 安装包未做商业证书签名及公证。更新保留本机数据。
