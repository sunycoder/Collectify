Collectify 5.7.0 增加“账号与更新”：可配置 GitLab 或 GitHub 地址与项目，使用 PKCE 浏览器授权或 GitHub 设备码登录。

- 私有插件目录和程序包通过用户授权下载，重定向到外站时不携带 Token。
- 主程序与插件自动检查更新；主程序按系统和架构下载，大小与 SHA-256 校验成功后，由用户确认启动安装器。
- 团队默认配置按真实用户组匹配，预览后应用；保留个人修改和已删除的默认内容，不自动执行或启用插件。
- 系统安全存储加密授权凭据，不将授权放入工作台导出数据。
- 增加 GitLab CI、Generic Package Registry 发布脚本与统一更新清单，发布地址可配置。
- 设置统一为固定尺寸的左侧导航，登录页仅展示当前服务与账号操作，项目和 OAuth 配置收进维护者高级设置。
- 本地搜索作为默认插件提供，优先使用已安装 Everything，支持分类搜索、文件预览及打开定位；分类使用宿主左侧导航。具体支持与限制见 docs/LOCAL-SEARCH.md。

公司侧需要登记非机密 OAuth 应用，回调 `http://127.0.0.1:19287/oauth/callback`，权限 read_api；需要为所支持的系统配置对应 Runner 并启用 Package Registry。详见 docs/GIT-SOURCES.md。

自动测试使用隔离数据、模拟 API 和测试令牌；公司 GitLab 的实际授权及发布能力需要在部署环境联调。安装包未签名，macOS 未公证；本版不提供静默安装或 macOS 自动替换。更新保留本机数据，安装前可按需导出备份。
