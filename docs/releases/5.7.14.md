# Collectify 5.7.14

- 计算稿纸的数学键盘改为独立桌面窗口，可拖出主程序或移到其他显示器；空白处可拖动，按键写入原稿纸的当前选区。键盘窗口不创建第二份稿纸数据，停用、卸载或退出时回收。需要计算稿纸 1.0.4。
- 插件导航支持拖动排序、键盘调整和顺序迁移；单入口插件默认收起二级导航，保留手动展开。
- 插件市场补充详情、截图、权限、能力边界及平台验证记录；已安装页显示可更新版本并可直接更新。
- 增加通用任务摘要和取消入口；Diff 接入离开保护、文本草稿恢复、另存和偏好备份。
- 便签与待办补充未保存修改确认，便签无匹配结果可清除筛选。
- 本地搜索支持调整结果/预览宽度和放大预览；JSON 补充行号、错误定位、单栏放大和撤销清空。
- IP 查询补充历史归属地与供应商缺失字段说明；剪贴板列表提供直接粘贴入口。
- 新增独立可选 Diff 插件：文本、图片、目录与 Office/PDF 本地比较，支持离线 OCR、表格业务键配对与差异报告。

主程序与可选插件分别更新。插件程序不包含用户数据，更新保留原数据。计算稿纸 1.0.4 最低需要本版本；其他插件最低主程序要求见插件详情。

Windows、macOS、Linux 的构建与桌面回归结果以本次发布流水线为准。安装包未做商业证书签名，macOS 未公证。
