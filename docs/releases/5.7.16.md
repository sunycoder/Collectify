# Collectify 5.7.16

- 数学键盘随计算稿纸显示：切换插件、打开设置、隐藏或最小化主窗口时隐藏，返回稿纸时恢复原位置；手动关闭后保持关闭。支持临时取消置顶，并显示正在输入的稿纸、行号和公式。需要计算稿纸 1.0.7。
- 计算稿纸的小数位菜单使用统一下拉控件；键盘输入、点击按键、选区替换及清空本行共用撤销/重做，支持 Ctrl/Command+Z。长公式和结果可换行展示。
- 便签支持最近修改或手动固定顺序，可拖动、向前或向后移动；编辑和筛选不会打乱手动顺序，重启及备份恢复保留排列。长标题换行，长正文可滚动。
- 本地搜索增加名称、目录、大小、修改时间四列，支持拖动或键盘调整列宽、双击恢复，自动保存列宽偏好。完整路径可悬停查看。需要本地搜索 1.2.3。
- Diff 导出前展示文件、工作表、差异数量及生效规则，可选择仅差异或包含上下文；确认前重新核对内容，避免导出已变化的结果。需要 Diff 1.0.6。

请先升级主程序，再分别更新可选插件。计算稿纸 1.0.7 最低需要主程序 5.7.16；其他插件的最低要求见插件详情。程序包不包含用户数据，升级保留原有数据。

Windows、macOS、Linux 构建和自动化回归结果以本次发布流水线为准。macOS 安装包未做商业证书签名及公证。
