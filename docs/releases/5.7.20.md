# Collectify 5.7.20

- 主程序增加自动更新。使用期间发现新版，在左下角显示“重启更新”；点击后先下载、校验，再保存工作、退出安装并重新打开。启动检查时尚未开始操作则自动执行，开始操作或选择“稍后”则等待主动重启。
- 支持下载进度、失败重试、手动安装及已下载安装包复用；退出被插件阻止时不安装，损坏安装包不会执行，安装未完成的版本不重复自动重启。
- Windows 使用 NSIS 静默安装并在失败时尝试恢复应用备份；macOS 校验 DMG 中的应用 ID 和版本后替换可写目录中的应用包，保留上一版本与系统安全检查；Linux AppImage 原位替换，deb 经系统包管理器安装并保留授权步骤。
- 优化宿主设置缓存，减少重复数据库查询、版本标记及相同设置的写入；插件重新发现不重复提交未变化记录。
- 公共 SDK 资源增加有界缓存，开发目录修改后自动失效；公共控件脚本并行请求并保持执行顺序。插件页缓存从四页增加到六页，默认五插件切换复用原页面。
- 插件栏、二级导航及主题只在实际变化时更新；开发模式加载超过 800ms 时输出分段耗时，便于定位页面载入、后台准备及重建问题。

本次仅发布主程序，插件版本不变，更新保留本机数据。5.7.19 及更早版本需先手动安装本版，之后才能使用新自动更新流程；开发运行不会自动替换源码。

本地 Windows 验证：235 项测试通过、1 项 Linux 专属测试跳过，完整宿主回归、更新气泡、更新设置页、代码及契约检查通过。Windows 安装助手通过隔离假安装器验证真实父进程退出后继续执行、静默参数、重开与损坏包拒绝；不等同于真实安装包端到端升级验收。

三系统构建与自动化检查以本次流水线结果为准。macOS/Linux 真实安装升级、Mac 用户设备启动速度尚未实机验收；macOS 安装包仍未商业签名及公证，目录权限、Gatekeeper 和 Linux 系统授权仍可能需要用户操作。不宣称已解决全部 Mac 性能问题。
