# Collectify 5.7.17

- 收藏的文件或目录失效时，可直接重新定位并打开，保留分类、备注和登录资料；新增多选整理和批量移动，明确显示筛选外的已选数量。
- 待办可快速调整为 10 分钟后、1 小时后、明天上午 9 点或自定义提醒时间，保留原截止日期。
- 计算稿纸支持按名称、备注和公式搜索，展示内容摘要，可固定常用稿纸。需要计算稿纸 1.0.8。
- 本地搜索区分完整无结果与搜索未完成，显示待检查或无法读取的目录，支持保留进度继续扫描。需要本地搜索 1.2.4。
- 收藏、待办和便签的常用单条修改采用增量事务提交；保留版本冲突检查、审计及旧数据迁移兼容。
- 拆分插件管理、市场界面和独立窗口模块；引入请求与响应契约、静态检查、性能基准和诊断。
- Diff 和本地搜索文档解析使用独立计算进程，支持任务取消及停用回收；卸载清理超时保留程序与数据。需要 Diff 1.0.7 或本地搜索 1.2.4，二者最低需要主程序 5.7.17。
- 收藏和便签分批显示长列表；便签在无编辑弹窗且可恢复时参与页面回收，恢复保留筛选。其他页面维持原有生命周期。

请先更新主程序，再分别更新可选插件。插件包不包含用户数据，升级保留原有数据。

本地 Windows 验证包括 209 项测试、完整宿主回归、插件专项、安装包构建及打包版操作与独立进程检查。三系统发布构建与自动化回归结果以本次流水线为准。macOS 安装包未做商业证书签名及公证。
