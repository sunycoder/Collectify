Collectify 5.7.2 改善桌面快捷入口和收藏夹导航。

- 剪贴板历史 2.2.0 支持桌面快捷按钮：在剪贴板页面点击“桌面快捷按钮”开启。透明窗口 48×48，拖动外圈调整位置，单击中间图标唤起主窗口并切换到剪贴板历史，右键隐藏。位置与开关会保留，停用或卸载插件关闭按钮。
- 收藏列表只滚动内容，返回网页入口固定在上方；网页工具栏中的返回收藏夹始终保留在视野内。

剪贴板需在插件市场独立更新至 2.2.0，最低主程序版本为 5.7.2。本地搜索仍为独立市场插件，不随主程序预装。

Windows 打包验证、桌面回归与单元测试通过；macOS/Linux 由各系统构建，桌面行为仍需实机确认。安装包未签名，macOS 未公证。
