# Collectify 5.7.18

- 收藏、待办、便签、时间戳和 JSON 工具改为可独立下载、安装、更新和导出的标准插件；“默认安装”不再限制单个插件发版。
- 安装包携带五个初始插件包，首次启动安装到用户插件目录并默认启用，离线也可使用。后续主程序升级不覆盖已更新插件，不重装已卸载插件。
- 升级保留原插件 ID、数据库、导航顺序和启停状态。卸载保留数据时可离线恢复保留版本；彻底删除后恢复不会重新灌入旧数据。
- 收藏、待办和便签的业务后台打入各自签名插件包；辅助窗口资源随插件分发，宿主通过公共后端接口提供能力。
- 插件市场共提供 11 个插件，五个默认安装插件与可选插件统一使用版本检查、包校验和更新流程。

本次默认安装插件版本：收藏 1.0.3、待办 1.0.3、便签 1.0.4、时间戳工具 1.0.2、JSON 工具 1.0.2，最低需要主程序 5.7.18。请先升级主程序，之后可在插件市场分别检查和更新插件。

本地 Windows 验证包括 212 项测试、完整宿主回归、默认插件专项和打包版启动验证。三系统构建及自动化回归以本次发布流水线结果为准。macOS 安装包未做商业证书签名及公证。
