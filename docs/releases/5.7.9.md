本版让插件自己拥有左侧入口图标，并新增独立的 IP 地址查询插件。

- 宿主支持清单中的包内 SVG 图标路径，按需读取并缓存；不再要求新插件把图标登记到主程序 assets。保留旧插件兼容，校验路径、类型和大小，停用或更新时拒绝旧请求结果。
- 收藏、待办、便签、JSON、时间戳的图标迁入各自插件目录，外观保持原样。
- IP 地址查询 1.0.2 独立安装，支持公网 IPv4/IPv6、归属地、运营商、历史记录、缓存及数据源设置；无常驻进程、端口或轮询。左侧入口与页面使用指定 IP SVG。
- 数据源下拉框使用统一浮层控件，仅首次打开设置时加载；Key 移除操作说明用途并支持撤销，保存才生效；点击弹窗空白处可关闭并放弃修改。
- 剪贴板历史 2.2.5、本地搜索 1.2.1 同步改为携带自己的入口图标，业务行为不变。

请先升级主程序至 5.7.9，再在“设置 → 插件 → 发现插件”安装或更新相应插件。IP 查询不会随主程序自动安装。查询需要网络，数据源返回的归属地是估算，出口 IP 可能受代理影响。

安装包未签名，macOS 未公证。云端回归不能替代真实系统的全部手工验证；本地搜索在 macOS/Linux 的压缩包预览和 Linux 主动粘贴仍有既有功能限制。
