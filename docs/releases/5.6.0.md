Collectify 是一个可扩展的个人插件工作台，默认提供收藏、待办与日历、便签、JSON 和时间戳。

本版增加统一插件导航、官方目录、独立插件安装更新、AI 插件开发，以及网页默认浏览器设置。剪贴板历史 2.1.1 是独立插件，在“设置 → 插件 → 发现插件”中安装。

| 下载文件                                 | 适用系统                |
| ---------------------------------------- | ----------------------- |
| `Collectify-5.6.0-windows-x64-setup.exe` | Windows 10/11 x64       |
| `Collectify-5.6.0-macos-arm64.dmg`       | Apple Silicon Mac，试用 |
| `Collectify-5.6.0-macos-x64.dmg`         | Intel Mac，试用         |
| `Collectify-5.6.0-linux-x64.AppImage`    | Linux x64，试用         |
| `Collectify-5.6.0-linux-x64.deb`         | Debian/Ubuntu x64，试用 |

Windows 已做桌面交互与打包启动验证。macOS/Linux 在对应系统构建并核对包内文件，尚未完成手工桌面实测。本次安装包未做商业签名或 macOS 公证，系统可能显示来源确认。

Windows 用户退出旧版本后直接安装更新，用户数据保留。首次安装不需要 Node.js、Git 或数据库环境。插件会检查最低主程序版本，不兼容时提示先升级。

附件只包含安装包和 SHA256SUMS.txt，不需要下载 Source code 源码包。遇到问题请在 Issues 附上系统、主程序和插件版本。
