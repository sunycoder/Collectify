# 架构优化与验证边界

本批改动保留 5.7.17 操作体验优化，发布验证结果见本版本的 CI 与发布流水线。

## 数据与依赖

- 公共 `domain-store` 不再继承旧版全业务 Store，也不导入任意业务模型。插件定义提供自己的校验和方法，领域数据按插件分库。
- 旧版兼容 Store/Repository 移至 `src/legacy/`；`src/store.js` 与 `src/sqlite-repository.js` 继续保留兼容入口，迁移数据保留 ID、凭据、附件与关联。
- 收藏保存/最近打开、分类编辑、待办保存、便签保存使用实体提交；不复制和校验全部业务集合。数据库事务同时校验 revision 并记录审计，提交成功后才替换内存。
- 导入、删除重排及批量替换仍完整校验，仓储仅写变更记录。名称交换先释放本批唯一键；附件只重建变化任务的附件。

## 结构与契约

- `src/host/plugin-management.js` 承担安装、更新、导出、卸载与恢复；主入口注入依赖和状态，不共享第二份窗口或插件注册表。
- `src/shell/plugin-market.js` 承担市场界面；`plugin-windows.js` 承担独立窗口与快捷按钮。运行时仍协调身份、权限、页面和后台生命周期。
- Provider 可声明动作契约；便签、待办已接入请求检查和稳定错误码。未迁移的可信插件继续兼容原接口，未声称所有动作均已类型化。
- ESLint 覆盖宿主主入口、提取模块与本次关键公共层；JSDoc/checkJs 覆盖请求合同及便签、待办动作合同。旧业务前端未一次性强制静态检查。

## 计算隔离与页面内存

- Diff 解析/目录扫描/OCR/报告及本地搜索文档预览，通过宿主注入的任务工厂在独立子进程内运行原工作线程。子进程故障不直接终止主进程，任务仍保留线程内存上限。
- 每插件同时最多两个计算任务；任务仅允许插件目录中的真实入口。停用回收进程，超时终止计算。系统对话框、凭据、Provider 编排和数据库提交仍在主进程；这不是第三方原生代码安全沙箱。
- 卸载阶段增加有界等待；在途数据提交或释放超时后保留程序和数据库、阻止新调用，任务结束可重试。不会为了结束等待而删除仍在写入的数据。
- 页面只有主动声明安全时才参与回收，活动页面、后台页、独立窗口、运行任务和资源读取均受保护；超过四个缓存页面或下次切换发现闲置十五分钟时回收候选。
- 便签是首个实际接入页面：编辑弹窗期间不回收，恢复时还原搜索与颜色。其他编辑器尚未声明安全，不会被自动回收。没有定时唤醒空闲插件。
- 收藏/便签首批各显示 100 条，可继续加载；收藏未变卡片复用，避免重新创建全部内容。后台 state 仍兼容全量快照，未迁移为所有插件的远程分页协议。

## 性能与验证

`npm run bench` 在隔离临时库中测试 100/1000/5000 条收藏，记录实体更新 P50/P95、完整快照提交 P50及实际写入实体数。输出 `dist/architecture-benchmark.json`，CI 三平台分别保存结果；门槛测试检查单条操作仅写一条实体，不设置跨机器的绝对毫秒门槛。

本机首次测量：5000 条时实体更新 P50 16.78ms，完整快照提交 P50 71.19ms；该对照不是旧发行版总体性能对比，不代表所有机器有同等收益。

宿主已有启动埋点继续保留；`workspace-info.performance` 增加操作耗时 P50/P95、页面数、后台页数和 Electron 进程 CPU/内存快照。操作指标有界，不记录参数、正文、路径或凭据。

新增验证覆盖实体事务、名称交换、过期 revision、进程成功/崩溃/停用、清理超时重试、长列表分页和页面回收恢复。Windows 执行完整测试与打包验证；三系统构建与自动化回归结果以本次发布流水线为准。
