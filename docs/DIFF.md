# Diff 可选插件

Diff 1.0.4 是独立、按需安装的可信原生插件，最低需要 Collectify 5.7.12。宿主只增加 `collectify.files.paths(File[])` 拖放路径转换和 TTF 字体 MIME 支持，不包含 Diff 业务。插件自带指定 SVG、Monaco、PDF.js、SheetJS 和解析工作线程，不依赖本地搜索或其他插件，不注册 AI/MCP 工具，不连接网络，不执行文档中的宏、脚本或公式。

## 使用

1.0.4：表格工具面板展开“按业务键匹配行”，选择 ID 或多列组合键。首行作为表头；两侧列位置不同时先开启“按表头匹配列”。仅唯一、完整的键参与配对，保留原单元格地址并统计匹配/修改/独有行；重复键、空键明确标记为独有行，不强行匹配。业务键使用显示值，受忽略空格/大小写和日期标准化设置影响，不使用公式文本。换文件、工作表或切换表头映射会清除键选择。业务键只作用于当前工作表，其余表报告保持按行比较；存在异常键时阻止业务键报告导出，修正或取消业务键后可导出。该功能在 Windows 实际回归，macOS/Linux 本轮未实机运行。

1.0.3（需宿主 5.7.12）：偏好纳入统一备份，不导出工作正文或草稿；内存编辑增加离开保护和文本另存。关闭、停用、卸载、重载、更新或导入之前刷新最后一次输入，再确认取消/放弃/保存文本草稿。自动草稿默认关闭，由用户主动开启，仅包含最近的文本对比工作副本，不包含图片/表格编辑；不会默认保存敏感输入，重开显示恢复入口，可删除草稿。草稿不承诺保存所有模式或多张工作区内容。扫描、OCR、解析及报告可通过宿主任务面板查看并取消，未知进度使用不定进度条。插件详情显示验证范围、权限和格式限制。

1.0.2 增强：图片工具面板包含实际控件，不再只显示说明。支持分割、淡化、闪烁、滑块、高亮、绝对相减、富文本 OCR、OCR 文本与文件详情；支持右图旋转、翻转、平移、局部像素平移对齐、关注区域框选、差异区域列表与点击定位。图像居中显示，保留像素尺寸，不为铺满窗口拉伸；闪烁离开图片视图即停止。差异框以 12px 网格连通区域归并，像素统计逐像素计算，最多列出 200 个区域。

OCR 采用包内 Tesseract WASM、英文字库与简体中文字库，首次点击识别才加载，不访问网络，不注册 AI/MCP 工具。每次识别限制 400 万像素，较大画布会等比例缩小，单侧 60 秒超时，可取消。富文本 OCR 在图片上标注可选择的识别词框；OCR 文本视图提供纯文本及置信度，并可跳转文本 Diff。OCR 结果并非人工校对，复杂表格、艺术字、低清图片可能识别错误；图片 OCR 不自动代替 PDF 扫描件比较。

表格保留原有双栏 Diff，新增 Redline、原始、已更改、行与文件详情视图。侧栏支持显示值/公式、智能/单词/字符、按表头匹配列（重复表头按出现次序）、忽略空格、忽略大小写、隐藏未更改行列、原有单元格填充色、排序和日期标准化（US/EU）；外观支持字号、密度、换行。仅基础填充与显示值格式可保留，不承诺完整复刻 Excel 字体、边框、合并单元格或条件格式。右侧变更列表可定位并翻页，双击可编辑内存副本，导出当前视图 CSV 或完整差异 HTML/JSON/PDF 报告；CSV 按当前单侧视图及筛选顺序导出。

文件夹默认同路径对齐，缺失项显示占位行，整行状态着色，显示仅左/仅右/已修改/类型冲突/未更改统计，支持路径搜索和同步滚动。可关闭“同路径对齐”恢复两侧独立浏览；侧栏列出前 150 个匹配文件作快捷导航，主目录与报告不截断，仍遵守原有扫描上限。

1.0.1 打磨：所有下拉框复用宿主 Tom Select 与顶层浮层，语言、文件配对支持搜索，空目录时禁用选择框。不同模式只在会话内独立保留内容，切换模式不混入旧文件；文件夹未选齐时显示等待状态，不启动扫描。连续单文件拖放先填空位，两侧都有内容后按落点替换，输入任务按顺序执行。

文本区增加文件路径、类型、大小与内存编辑标记，差异编号、当前块边线和左右连接带。F7 / Shift+F7 导航，当前差异可向左或向右应用并撤销；计算未完成时等待当前结果再合并。合并不改原文件，刷新按钮可重新读取文件；切换模式保留当前内存编辑，清空只清当前模式。工具栏可收起，窄窗口可打开浮动工具面板。文档切到文本差异后提供返回预览入口。

1. 使用包含通用拖放能力的主程序，在“设置 → 插件 → 安装插件包”选择 `collectify.diff-1.0.3.collectify-plugin`。
2. 选择文本、图片、文件夹或文档。可以打开文件、拖入一到两个文件，或通过左右“粘贴”读取复制的文件、截图和文字。打开插件时，只尝试接收剪贴板内的文件列表，不自动导入普通文字。
3. 文本为 Monaco 双栏编辑器，支持统一视图、逐字符高亮、换行、折叠未修改区域、前后差异定位、查找与撤销。语言按扩展名识别，手动选择后持久保留；右侧编辑器右键“打开设置面板 / 切换语言模式”可定位设置。
4. 忽略引号、破折号和指定词只改变对比显示，不覆盖原文；启用这类规则时暂时只读，清除规则恢复原文。文本转换作用于两侧内存文本，不改原文件。比较精度设为智能或标准；报告支持 HTML、JSON、PDF。
5. 图片支持左右、差异高亮、淡化叠加、滑动四种模式，滚轮缩放、按住拖动和适应画布。左上角对齐，容差可调；差异模式显示变化像素数。支持 PNG、JPEG、WebP、GIF、BMP，动图只比较静态首帧。可导出当前画面 PNG，HTML/PDF 报告也包含当前画面。
6. 文件夹自动递归扫描，用 SHA-256 判断实际内容。橙色为内容或修改时间不同，红色为仅左、绿色为仅右、紫色为类型冲突。目录橙色数字累计子目录的差异文件数。仅时间不同但内容相同会单独标明。
7. 单击文件按同路径配对，Ctrl / macOS ⌘ + 单击或底部两个下拉框可手动指定。双击目录进入、箭头展开收起、面包屑返回，两侧独立。下拉框可选子目录，底部展示子目录差异并继续打开文件。支持仅差异、刷新、交换及强制重算指纹；目录报告包含所有扫描差异与警告。

## 文档范围

| 格式             | 对比与预览                                                                                                                                                 |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| DOCX             | 正文段落文本对比，不检测样式、图片、页眉页脚或排版差异                                                                                                     |
| XLSX / XLS / CSV | 按工作表名称和单元格坐标左右预览；对比显示值或公式；差异高亮；行列分页，报告包含所有工作表的差异                                                           |
| PDF              | 使用本地 PDF.js 按页渲染，左右预览和当前页像素差异高亮；文本视图和报告可提取全部页面文本。扫描件没有 OCR，不把空文本当成视觉相同；字体替代可能影响视觉结果 |
| PPTX             | 按幻灯片原始顺序提取文本、图片、基础形状位置，左右基础预览与当前页像素差异；可切换全稿文本对比。不保证母版、图表、SmartArt、复杂样式或动画完全还原         |

## 性能、数据和边界

- 未打开插件时不读取对比文件、不创建数据目录、不启动工作线程。Monaco 首次进入文本页加载，PDF 库只在打开 PDF 时加载；不增加默认插件，也不随宿主安装包分发。
- 原始文件始终只读。仅语言、显示和忽略规则等偏好写入插件自己的 `preferences.json`，不自动保存文件内容、截图或历史；报告只写用户通过保存窗口选择的位置。
- 扫描、文件指纹、Office 解析和报告差异计算在可取消 Node 工作线程；像素差异使用页面 Worker，Monaco 使用独立编辑器 Worker。停用、取消、更新或卸载会终止任务并撤销预览资源。
- 单文件最多 32 MiB，文本最多 200 万字符；图片或对齐画布最多 1600 万像素。每侧目录最多 20000 项、64 层，不跟随符号链接。超限、不可读或变化中的文件明确提示，不能被标记为相同。
- Office 解压总计不超过 64 MiB、单项不超过 32 MiB、5000 个条目；PDF/PPTX 最多 300 页。单个 Excel 表最多 25 万单元格、1000 列、50000 行，工作簿最多 100 表、50 万单元格。表格每页显示 100 行、30 列；超限拒绝解析，不悄悄截断。单次工作线程 60 秒超时，编辑器差异计算上限 3 秒，差异报告另有计算上限。
- 预览资源使用随机会话票据，停用即撤销，原文件变化时要求重开。文件夹配对拒绝越界路径和链接穿透。导出 HTML 转义文本并禁用脚本，PDF 报告使用隔离的隐藏窗口。

## 构建与验证

依赖锁定在 `plugins/sources/diff/package-lock.json`，维护者运行 `npm ci --prefix plugins/sources/diff --ignore-scripts`。SheetJS 使用已有官方 0.20.3 构建输入 `build-tools/sheetjs/package`；最终依赖打包进 Diff 自己的 vendor，不在运行时读取其他插件。

```powershell
npm run diff:build
node scripts/sign-native-plugin.cjs src/plugin-library/diff
npm run plugins:build
node --test test/diff.test.js
npm run smoke:diff
```

Windows 本机回归覆盖真实签名安装、Monaco、拖放事件、复制文件与粘贴图片、DOCX/XLSX/XLS/PDF/PPTX、文件夹内容指纹、配对、HTML/JSON/PDF 导出和热插拔。CI 已添加 Windows、macOS、Linux 的独立回归入口；未运行的系统不视为已实机验证。
