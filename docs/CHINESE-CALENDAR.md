# 日历可选插件

`collectify.chinese-calendar` 1.0.1，要求 Collectify 5.7.9 或更新版本。基于 MIT 开源项目 he-calendar 1.5.2 原组件适配，保留页面布局和主要交互，使用指定的“日历.svg”作为插件入口及页面图标。与默认“待办与日历”插件独立，无共享业务数据。

## 功能

- 24 节气自动主题，以及素雅、水墨、朱红、鎏金、黛蓝五种固定风格；支持日间、夜间和跟随宿主主题。
- 公历与农历、节气、传统节日、内置假期/调休、干支、生肖、宜忌、五行纳音、冲煞、彭祖百忌、胎神、十二时辰。
- 滚轮切换月份、点击年月快速选择、回到今天、日期与今天的天数差、周一/周日起始、节日类型开关、节日倒数与百科链接。
- 手动搜索城市，显示当前天气、体感温度、湿度、风速、逐时预报和今天之后未来四天预报。天气位置与开关重启保留。
- 五个只读 MCP 工具：`calendar_get_date_info`、`calendar_get_almanac`、`calendar_get_festivals`、`calendar_search_next_festival`、`calendar_get_shichen`。在宿主设置启用 AI/MCP 后可用；停用插件后撤回，不另开端口。

日期输入支持 1901-01-01 至 2099-12-31。节日区间查询含首尾最多 400 天。节假日/调休使用 tyme4ts 1.5.5 内置数据，不能将没有记录的未来年份视为已确认安排，以官方公告为准。黄历和时辰宜忌仅为传统民俗资料。

## 安装与生命周期

1.0.1 新增可选待办联动：日期格展示事项数，侧栏展示选中日期的计划、截止时间和状态。计划与截止分开识别，同日同事项只计一次；有明确起止时间的跨日计划按半开区间覆盖日期（午夜结束不多算一天）。全天事项遵循现有待办日历的单日语义。归档项不展示，已完成项以淡色划线保留；没有计划或截止日期的事项只提示总数，不把创建/提醒时间当成安排日期。

联动通过现有宿主上下文的 `available/invoke/open` 与 `collectify.tasks` 的只读 `state` 契约访问，不导入待办代码、不读取对方数据库、不缓存持久化待办或更改其状态。返回日历、切换月份/周起始、页面恢复焦点或点击“刷新”时更新；可从“打开待办”进入对方列表。未安装、停用或接口失败时清空旧标记并展示提示，历法/天气独立使用。没有日历插件时，待办完全不受影响；不要求升级主程序或修改待办插件。

在“设置 → 插件 → 安装插件包”选择 `collectify.chinese-calendar-1.0.1.collectify-plugin`。首次打开显示日历，未选择城市不会联网。设置页搜索城市并选择结果后获取天气。

后台对象创建和启用不加载历法库、天气模型、Electron、SQLite 或 MCP schema，不初始化配置、不联网、不启动定时器。页面只有实际打开后才运行；MCP 查询按需加载离线历法，天气按需使用 Electron net.fetch，复用系统代理和证书。插件采用已有原生后台签名机制，安装时显示 native 权限，不代表独立进程沙箱隔离。

页面可见且天气已配置时，每 30 分钟刷新一次；隐藏/切换后暂停刷新及请求。停用、卸载和退出取消在途任务，缓存清理，迟到响应不得更新页面或缓存。重新启用不需重启宿主。历法查询无网络依赖，天气服务失败不影响月历与黄历。

## 天气和数据

天气沿用上游的小米天气接口。仅访问固定 HTTPS 服务，禁止重定向及 Cookie，每次请求上限 1 MiB、15 秒超时；城市搜索与预报分别缓存 5/10 分钟，最多 30 个缓存项。缓存结果保留原取数时间，供应商更新时间单独返回。没有返回有效当前温度时明确报错，不能将异常响应伪装为 0°C。供应商可用性、配额及预报范围不由插件保证。

桌面版不申请浏览器地理定位，使用原项目的城市搜索模式。查询会发送城市名或所选城市经纬度；未启用天气时不上传位置。天气公共请求参数集中在 `defaults.json`，来源于上游公开实现，不包含用户凭据。

设置保存到插件自己的 `data.sqlite`，支持宿主全局备份导入导出，卸载默认保留数据，选择删除数据时清理。输入设置格式错误不会覆盖已有配置；设置保存失败时页面提示并提供重试。

## 构建与验证

上游来源、许可证、改动及构建命令见 `plugins/sources/he-calendar/README.md`。运行包随带 MIT 许可证和各依赖的许可证；Vue、tyme4ts、dayjs、图标组件均打包，无 CDN、远程脚本或字体依赖。

```sh
node --test test/chinese-calendar.test.js
npm run smoke:calendar
# 显式访问真实供应商查询公共测试城市；日常 CI 使用隔离天气数据
npm run smoke:calendar -- --live-network
```

测试覆盖冷启动、离线历法、日期边界、SQLite 重启和备份、天气限时与缓存、取消/隐藏/停用、MCP 真实客户端与工具撤回。界面冒烟覆盖原 Vue 页面、月份、农历黄历、日期距离、主题、周起始、天气三段卡片、四天预报、窄屏及卸载重装。Windows 已本地执行；macOS/Linux 已接入 CI，未运行前不标记已通过。
