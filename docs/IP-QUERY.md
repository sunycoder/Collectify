# IP 地址查询插件

`collectify.ip-query` 1.0.2 是独立可选插件，要求 Collectify 5.7.9 或更新版本。支持 Windows、macOS、Linux，不随主程序默认安装。

## 使用

- 安装 `.plugin-release/collectify.ip-query-1.0.2.collectify-plugin`：设置 → 插件 → 安装插件包，选择插件包。目录发布后也可从“发现插件”安装。
- 首次打开页面时查询公网出口 IP；输入 IPv4 / IPv6 后回车查询，空输入查询自己的出口。可复制 IP、取消查询、点击历史再次查询。
- “刷新公网 IP”绕过缓存。指定地址缓存 5 分钟，公网出口缓存 1 分钟，最多 50 条缓存；本机历史最多 30 条。清空记录同时取消查询并清除缓存。
- 内网和常见保留地址在本地解释，不发送到外部服务。不接受域名、URL、端口、网段或 IPv6 zone ID。
- 数据源设置提供 IPWhois 与 IPinfo Lite。IPWhois 无需 Key；IPinfo Lite 需要个人 Key，主要返回国家和 ASN，不提供城市坐标。供应商可用性、字段和额度以其实际服务为准，插件不会自动切换供应商或重复重试扣费。

## 生命周期与启动

后台对象的创建和启用只分配轻量状态。不建库、不读取用户配置、不加载 Electron 网络/密钥环、不联网，没有常驻进程、监听端口、后台页面或轮询。首次页面调用 `state` 才初始化插件自己的 SQLite 文件，实际查询才调用 Electron `net.fetch`，复用系统代理和证书。

界面使用已有 SDK 暴露的 IPC、剪贴板和主题令牌；首次打开设置时才加载宿主现有下拉控件与浮层资源，不加载日历、地图、字体或图标包。宿主运行代码没有 IP 查询专属分支，也不导入 IP 插件模块。已有宿主机制仍会进行插件发现、签名校验和轻量后台创建，因此不能宣称安装任意插件的启动成本为绝对零。

连续查询会取消旧请求；取消覆盖连接和响应体读取。停用、卸载、退出时中止请求、清除内存缓存，并使迟到响应失效。重新启用无需重启主程序。卸载默认保留自己的数据，选择删除数据时删除该插件目录。

## 数据与边界

- 查询仅访问插件内固定的 HTTPS 服务地址，不接受任意网络 URL。禁止重定向、Cookie 携带；连接与响应体读取共享 10 秒超时，响应最多 64 KiB。
- 指定 IP 会发送给所选服务；“我的 IP”是该服务观察到的出口地址，代理、VPN 和网络变化可能影响结果，不保证展示本机物理网络的直连地址。
- 归属地是供应商估算，缺失字段不展示；不提供街道级个人定位、风险评分或离线地址库。
- IPinfo Key 经系统安全存储加密后保存在插件自己的 SQLite 中，不返回页面、不写进历史、不进入插件包。Linux 无安全密钥环或使用 `basic_text` 时拒绝保存 Key，免 Key 查询仍可用。
- 数据存放在宿主插件数据根目录下 `collectify.ip-query/data.sqlite`。插件包只含程序。IP 历史和 API Key 当前不参与全局导出，跨系统迁移 Key 需重新输入。
- 原生后台复用现有签名机制，拥有 `native` 权限；签名确认发布者身份，不等同于进程沙箱隔离。页面仍受 SDK 身份校验和沙箱限制。

## 开发与验证

```sh
node --test test/ip-query.test.js
npm run smoke:ip-query
# 显式访问供应商验证公共 IPv4 / IPv6；普通 CI 不依赖供应商网络
npm run smoke:ip-query -- --live-network
```

测试覆盖无启动 I/O、IP 边界、SQLite 重启、缓存上限、取消与迟到响应、停用卸载、接口错误、超限响应、系统密钥环、签名安装、真实沙箱页面与 IPC、文本防注入、历史记录和数据删除。三系统 CI 运行独立页面冒烟；Windows 实际执行结果与 macOS/Linux 尚待执行的检查应分别报告。

修改插件源码后，先格式化，再用 `scripts/sign-native-plugin.cjs` 和本机既有发布者私钥签名，运行 `npm run plugins:build`、`npm run plugins:check`。签名后不得再改插件文件。发布只需该插件的版本标签，不要求发布主程序。
