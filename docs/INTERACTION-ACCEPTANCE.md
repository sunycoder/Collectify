# 插件交互验收清单

适用范围：宿主插件导航、插件市场和插件贡献的任务；Diff 的文件加载、编辑、草稿与关闭流程。插件持有业务状态，宿主只提供可选的公共合同。

| 场景       | 交互要求                                                                                           | 当前验证入口                     |
| ---------- | -------------------------------------------------------------------------------------------------- | -------------------------------- |
| 导航排序   | 点击打开；达到拖动阈值后显示插入线；边缘滚动；Esc 取消；Alt + 方向键移动并保留焦点                 | smoke-navigation                 |
| 搜索       | 显示快捷键；无结果给清除入口；Esc 清除；Enter 打开第一个可用结果                                   | 宿主导航及人工检查               |
| 插件详情   | 说明能力、限制、权限和平台实测范围；缺失信息不伪造；安装/更新/打开主操作可见；长内容内部滚动       | smoke-product                    |
| 文件加载   | 显示加载、成功与失败状态；失败不能被判断为相同；新请求淘汰迟到结果；支持取消                       | diff.test、smoke:diff            |
| 无差异     | 区分无差异、未选择文件、读取失败；不把失败当作空文件                                               | diff.test、smoke:diff            |
| 编辑       | 原文件保持不变；修改只存在于工作副本；另存由用户选择新位置，拒绝覆盖当前原文件                     | smoke:diff                       |
| 草稿       | 默认不保存正文；自动保存由用户开启；可主动保存、恢复、删除；草稿不包含图片、表格编辑或原文件       | product-safety、smoke:diff       |
| 离开与退出 | 关闭、停用、卸载、重载、更新及导入前同步最后一次编辑；取消保留当前视图和内容；后台清理完成后才退出 | smoke-product、smoke-shutdown    |
| 后台任务   | 仅显示插件主动贡献的真实任务；未知进度不显示虚假百分比；取消准确作用于所属任务；切换插件不取消任务 | product-safety、smoke-product    |
| 导入导出   | 展示每个插件的备份范围；偏好迁移不夹带对比正文；失败回滚；缺失插件顺序不触发安装或启用             | product-safety、workspace-backup |
| 小窗口     | 主操作保持可见；长详情内部滚动；Diff 工具面板可折叠                                                | smoke-product、smoke:diff        |

上表是持续验收基线，不代表 macOS/Linux 已经实机通过。对应平台验证记录见 PLATFORM-VERIFICATION-2026-11-17.md。
