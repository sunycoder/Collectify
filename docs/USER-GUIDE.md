# 安装与使用

## 工作台搜索与批量插件操作

顶部“搜索工作台”统一查找插件及已启用插件保存的内容，Ctrl / ⌘ + K 打开，支持全部、插件、内容范围；结果可直接打开并定位。不会搜索收藏密码或令牌。

“设置 → 插件 → 已安装”检查更新后可选择多个插件批量更新，逐项展示成功、取消和失败；失败项可重新选择重试。

开发者选项中的“选择开发目录”支持项目根目录、插件集合或单插件目录，一次扫描后勾选加载。“重新扫描开发目录”复用上次目录；原生插件先构建并签名。开发加载允许同版本重载，正常市场安装仍要求程序变化时提高版本号。

Diff 的“对比组合”可保存两侧本地路径与规则，重开时读取磁盘最新内容；路径失效可重新定位。列表支持搜索，默认收起。组合路径和偏好可随插件备份导出，原始文件仍不包含在备份中。

## 调整插件顺序

在最左侧插件栏按住插件入口上下拖动，插入线表示松开后的位置；拖到栏的顶部或底部可自动滚动。也可聚焦某个插件入口后按 Alt + ↑ / ↓ 调整。普通点击仍打开插件，拖动时不会切换插件；拖动中按 Esc 可取消。

顺序保存在宿主偏好中，重新启动、停用再启用和更新插件后保留。新安装插件追加在已自定义排序的插件之后；搜索筛选时仅移动指定插件，不删除隐藏或停用插件的记录。“设置 → 插件 → 已安装 → 恢复默认顺序”可还原。导出和导入时勾选“宿主设置”，可以迁移导航顺序；缺失的插件不会自动安装或启用。

## 插件详情与任务

插件卡片的“详情”可查看功能、限制、权限、最低主程序版本、截图和平台验证记录。未声明的记录会明确显示，不代表所有系统都已实测。详情中的主按钮按状态提供安装、更新、打开或启用并打开。

支持任务贡献的插件在运行时会让顶部显示“任务运行中”，可查看所属插件、处理状态和取消。没有总进度的任务使用不定进度，不显示估算百分比。切换插件不取消任务，停用/卸载会清理任务。

## Diff 工作副本保护

Diff 1.0.3 需要 Collectify 5.7.12。文本可“另存”为新的文件；原始文件仍只读。关闭、停用、卸载、更新、重载或导入前，如有未另存编辑，会先提示取消、放弃，或保存文本草稿。

“文本工作副本 → 本机自动草稿”默认关闭；主动开启后仅保存文本，不保存图片、表格内存编辑、原始文件或访问路径。手动保存不打开自动记录，重开时可恢复或删除。草稿不随统一备份导出；统一备份包含 Diff 的语言、显示和忽略规则偏好。图片、表格请先导出结果，不能通过文本草稿恢复。

## 下载安装

在仓库首页点击适合自己系统的下载链接，或进入 Releases 选择最新版主程序。文件名带系统和架构，不需要下载 Source code，不需要安装 Git、Node.js 或数据库。

- Windows x64：运行 `-windows-x64-setup.exe`，按提示完成安装。
- Apple Silicon Mac：下载 `-macos-arm64.dmg`，打开后拖入 Applications。
- Intel Mac：选择 `-macos-x64.dmg`。
- Linux：AppImage 赋予执行权限后运行，Debian/Ubuntu 也可安装 deb。

macOS/Linux 暂为试用，验证范围及未签名状态见对应 Release 说明。

## 更新

设置 → 通用 → 下载与更新，打开最新主程序下载页。退出正在运行的旧程序后安装新版；同一应用身份下保留本机数据。暂不自动下载或替换主程序。

## 插件

左侧图标选择插件，侧栏顶部按钮收放内部导航。收藏、待办与日历、便签、JSON、时间戳默认提供。

设置 → 插件 → 发现插件，选择安装。官方目录无需手填地址；下载文件后也可用“安装插件包”离线安装。插件更新不需要重装主程序；如果提示最低主程序版本，先更新主程序。

设置 → 插件 → 已安装，可停用或卸载。停用保留数据；卸载可选保留或删除数据。默认插件支持恢复。

剪贴板历史需要主动开启采集；开启后关闭主窗口会驻留托盘，完全退出才停止。收藏登录资料按产品设计以明文保存在本机，可直接查看和复制。

## 数据与备份

实际目录见设置 → 通用 → 打开数据文件夹。Windows 通常为 `%APPDATA%\Collectify`，macOS 为 `~/Library/Application Support/Collectify`，Linux 通常为 `~/.config/Collectify`。

设置 → 导入 / 导出，可按插件选择内容并另选宿主设置。数据备份不包含插件程序、浏览器 Cookie、附件原文件或本机 MCP 令牌。更新前可先导出备份；卸载主程序默认保留用户目录。
