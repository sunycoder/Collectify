# 安装与使用

## 下载安装

在仓库首页点击适合自己系统的下载链接，或进入 Releases 选择最新版主程序。文件名带系统和架构，不需要下载 Source code，不需要安装 Git、Node.js 或数据库。

- Windows x64：运行 `-windows-x64-setup.exe`，按提示完成安装。
- Apple Silicon Mac：下载 `-macos-arm64.dmg`，打开后拖入 Applications。
- Intel Mac：选择 `-macos-x64.dmg`。
- Linux：AppImage 赋予执行权限后运行，Debian/Ubuntu 也可安装 deb。

macOS/Linux 暂为试用，验证范围及未签名状态见对应 Release 说明。

## 更新

设置 → 通用 → 下载与更新，打开最新主程序下载页。退出正在运行的旧程序后安装新版；同一应用身份下保留本机数据。暂不自动下载或替换主程序。

## 插件

左侧图标选择插件，侧栏顶部按钮收放内部导航。收藏、待办与日历、便签、JSON、时间戳默认提供。

设置 → 插件 → 发现插件，选择安装。官方目录无需手填地址；下载文件后也可用“安装插件包”离线安装。插件更新不需要重装主程序；如果提示最低主程序版本，先更新主程序。

设置 → 插件 → 已安装，可停用或卸载。停用保留数据；卸载可选保留或删除数据。默认插件支持恢复。

剪贴板历史需要主动开启采集；开启后关闭主窗口会驻留托盘，完全退出才停止。收藏登录资料按产品设计以明文保存在本机，可直接查看和复制。

## 数据与备份

实际目录见设置 → 通用 → 打开数据文件夹。Windows 通常为 `%APPDATA%\Collectify`，macOS 为 `~/Library/Application Support/Collectify`，Linux 通常为 `~/.config/Collectify`。

设置 → 导入 / 导出，可按插件选择内容并另选宿主设置。数据备份不包含插件程序、浏览器 Cookie、附件原文件或本机 MCP 令牌。更新前可先导出备份；卸载主程序默认保留用户目录。

## 反馈

通过仓库 Issues 选择问题反馈或功能建议，附系统、主程序版本、插件版本及复现步骤。截图和导出文件提交前自行移除账号密码与其他私人内容。
