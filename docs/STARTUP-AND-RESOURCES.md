# 收藏资料与启动行为

网页类型用于内置或系统浏览器访问，保持 HTTP/HTTPS 校验。账号资料用于密码本：关联地址可选，允许 SVN、SSH、服务器名称等参考信息，保存后只展示和复制，不自动交给系统执行。文本、文件、文件夹也可以附带账号密码，切换类型不再主动清除凭据。明文显示与复制沿用产品约定。

账号资料导入去重按分类、名称、关联地址和账号判断，避免同名的不同仓库资料互相覆盖。仅写用户名的地址不会清除表单单独填写的密码。

通用设置的开机自启动直接读取系统状态。Windows/macOS 使用 Electron 启动项接口；Linux 使用 XDG autostart，AppImage 使用外层持久路径。开发模式禁用开关，防止把开发运行时写进启动项；测试不修改真实系统设置。

启动优化包括：MCP SDK 在首次启用 AI 连接或获取连接信息时加载；默认插件清单按发现周期缓存；首个插件和宿主页面并行加载；插件后台与前台并行初始化；日历库延迟到打开日历视图加载。插件仍需初始化，不能在跨进程重启后复用已销毁的页面。

使用 `npm run smoke -- --startup-metrics` 输出主进程导入、注册表、业务服务、宿主页面和首个插件就绪时间。时间是从进程开始计算的本机样本，不代表所有设备或真实用户数据下的耗时。

macOS 全屏修复避免重复切换 WebContentsView 可见性、尺寸，资料卡不再在每次布局时先隐藏再恢复；资料卡采用不可全屏的面板，并在全屏进出动画期间收起。`--smoke-fullscreen` 在 Mac 真正进入原生全屏，用本机测试网页和测试凭据检查资料卡显示抖动。Windows 的相同测试仅验证布局链路，不能替代 Mac 实机检查。
